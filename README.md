# DietDesk

App per piani dietetici, per dietisti e nutrizionisti. Si apre da browser e si installa come app (iPhone: Safari → Condividi → Aggiungi alla schermata Home; PC: Edge o Chrome → Installa).
I dati restano sul dispositivo di chi la usa; la sincronizzazione facoltativa con Google Drive salva una copia cifrata nel Drive personale dell utente.

- Informazioni: https://dietdesk.github.io/info.html
